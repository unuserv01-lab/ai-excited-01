# DETIK SEBELUM — ai-excited-01

A tiny human silhouette stands on a dark plain before a colossal glowing
torus ring in the night sky. One focal point, extreme contrast, scale.

`main.py` (Python 3 stdlib only, no network, deterministic) renders the
image and writes it as a JPEG to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`), 1024x1024.

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`
